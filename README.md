# MetaMe downloads

Installers for MetaMe, a private identity wallet for Windows, macOS and Linux.

**Download page:** https://chevy30731.github.io/metame-releases/

This repository holds release builds only. MetaMe's source code isn't public yet.

MetaMe is early-access software. It hasn't had an independent security audit, and the installers aren't code-signed yet. Every release lists the SHA-256 of each installer in `SHA256SUMS.txt`.

Found a problem? [Open an issue](https://github.com/chevy30731/metame-releases/issues/new).
